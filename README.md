# johanberthling.com

This builds on the 'Template-Minimal' starter template for [Venue CMS](https://venuecms.com).

It is built with Next.js and uses the [Venue SDK](https://venue.gitbook.io/docs/sdk) to connect to your VenueCMS instance.

## Getting Started

First, install your dependencies:

```
pnpm install
```

Then run the development server:

```bash
pnpm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
